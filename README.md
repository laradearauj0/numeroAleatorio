# 🎯 Jogo de Adivinhação em Java

Um projeto simples em Java desenvolvido via console para praticar conceitos fundamentais de lógica de programação, como estruturas de repetição, condições e a biblioteca `java.util.Random`.

---

## 📌 Sobre o Projeto

O programa simula um jogo no qual o computador sorteia um número aleatório entre **0 e 100** e o usuário possui **até 5 tentativas** para adivinhar o número correto.

A cada palpite, o sistema informa se o número digitado é **maior** ou **menor** do que o valor secreto gerado.

---

## ⚙️ Funcionalidades

- Generação dinâmica de números aleatórios com a classe `Random`.
- Contagem regressiva do limite de tentativas (5 no total).
- Dicas em tempo real (número maior/menor).
- Encerramento automático ao acertar ou ao esgotar o limite de tentativas.

---

## 💻 Conceitos Praticados

- **Lógica e Controle de Fluxo**: Laço `while`, verificações com `if / else if / else` e interrupções com `break`.
- **Entrada e Saída de Dados**: Leitura via console com `Scanner` e exibição via `System.out.println`.
- **Manipulação de Bibliotecas Padrão**: `java.util.Random` e `java.util.Scanner`.
